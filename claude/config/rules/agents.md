# Delegation

Delegate for parallelism on disjoint work (read-only fan-out always qualifies), to keep noisy exploration out of the main context, or to verify a long build against its spec from a fresh context when no test covers it. `adversarial-reviewer` is reserved for the stakes named in CLAUDE.md. Otherwise work in the main session.

Every `Agent` call sets `model`: `haiku` for inventories, grep sweeps, log triage, format conversion, and other work with a checkable answer; `sonnet` for surveys, summaries, visual triage batches, and first-pass implementation in a well-specified area; `opus` or inherit for anything a reviewer would have to re-derive. A reviewer is never weaker than the author. For visual triage batches (more than ~10 images), tile into contact sheets (`~/.claude/skills/shots/imgtool.py sheet` or a quick montage script) and run on `sonnet`/`haiku` rather than reading hundreds of individual images on `opus`. Use `isolation: "worktree"` when agents could collide (an isolated agent edits with Write/Edit and literal paths; the guard refuses heredocs and indirect git), set `effort: "medium"` (inherited effort follows the session's), and resume a named agent with `SendMessage` rather than spawning fresh. Subagents do not call `update_plan` (desktop hides subagent plans and blocks the tool) and never poll background output with `sleep N && cat /private/tmp/...` (wait on Monitor or completion notifications). Conductor sessions follow the `conductor` skill.

`Explore` finds code: it starts without CLAUDE.md files and does not review or audit. Send audits, bug hunts, and diagnoses to `general-purpose`, or to `adversarial-reviewer` at the stakes named above.

A reviewer gets the work, not the author's verdict. For visual or behavioural review, pass screenshots or recordings plus the requirement, and leave out the builder's notes, diff summary, and conclusion: an agent handed a conclusion tends to confirm it.

A brief states the outcome, why it matters, what is in and out of scope, and any authorization already given, and asks for a terse report that says plainly what could not be verified. It names the authenticated CLI an agent should use (`gh`, `wrangler`) and never tells it to read a token or credential file.
