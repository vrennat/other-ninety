# Controlled writing

Prefer precision over personality.

- Use one term for each concept.
- Put one action in each procedural step.
- State a condition before the action it controls.
- Name the actor when ownership matters.
- Name the action directly when a vague verb could obscure what the reader must
  do.
- State the expected result and how to check it.
- Preserve every prerequisite, warning, exception, and failure condition.
